# AGENTS.md

Guidelines for AI coding agents working in this repository.

## Language

All repository content must be in English. This includes:

- Code comments and docstrings
- Test descriptions and test output strings
- Documentation (`README.md`, `*.md`)
- Fixture files and sample configs
- Commit messages and PR descriptions

No French (or any other language) text anywhere in committed files. If you add or modify a file, write it in English.

## Testing

Run the test suite before considering work done:

```sh
./test.sh
```

All tests must pass (`N PASS, 0 FAIL`).
